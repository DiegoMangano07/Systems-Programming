Exercise Session n. 1
Systems Programming

We practice with simple input/output operations. The functions we use are getchar for the input, and printf and putchar for the output.

Count Lines

Write a C program called countlines that counts lines in the standard input. A line is any sequence of zero or more characters terminated by the newline character '\n'. The output is the number of lines.

Minimal testing

Test your program by writing some input files and then running your program with those files as the program’s standard input.

Hacker tip: The output of your program should be the same as that of the command wc -l. Hopefully you have the wc utility installed and available on your system. (If you are a hacker then you must have it.)

Count Empty Lines

Write a C program called emptylines that counts and then outputs the number of empty lines in its standard input. As in the countlines exercise above, a line is defined as a sequence of zero or more characters terminated by the newline character '\n'.

Minimal testing

Test your program by writing some input files and then running your program with those files as the program’s standard input.

Hacker tip: The output of your program should be the same as that of the command grep -c -e '^$'. Hopefully you have the grep utility installed and available on your system, too. (Needless to say, …)

Paragraph Enumeration

Write a C program called enumpar that reads a text from its standard input, and copies the text onto its standard output by formatting and enumerating each paragraph. A paragraph is a maximal contiguous sequence of one or more non-empty lines. The program must output each paragraph indented by six spaces, with a counter printed at the beginning of the first line of each paragraph. More specifically, the text of each line of a paragraph (non-empty, by definition) starts at column 6, and the first line of the paragraph also contains the paragraph counter printed as a number right-aligned to column 5.

Paragraph in the input may be separated by one or more lines. However, the output paragraphs must be separated by a single empty line. The paragraph counter starts at 1.
