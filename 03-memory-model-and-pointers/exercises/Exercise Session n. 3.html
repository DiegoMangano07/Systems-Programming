We start practicing a bit with C strings. We have yet to study strings in detail. However, we can just use a quick and informal definition, and then proceed intuitively.

In C, a string is an array of characters (char) terminated by a special “terminator” character. The terminator char is 0. Recall that char objects are just numbers, so 0 is a valid char. Also notice that the terminator is the number 0, not the character “0”. In your code, you can simply write 0, or '\0' (but again, not '0'). You can even put a 0 character in a literal string, like so: "here comes the terminator: \0".

So, we define a string as an array, but we haven’t seen arrays either. Well, what can I say, use the force, Luke! For our purposes, an array is a sequence of elements that can be accessed individually by their position (or “index”). For example, in the following code, we have a function called print_first_k that prints the first \(k\) characters of a given string \(S\). 

void print_first_k (char S[], int k) {
    for (int i = 0; i < k && S[i] != 0; ++i)
        putchar(S[i]);
}

int main () {
    print_first_k ("ciao", 2);
}

Notice that we stop printing as soon as we reach the terminator character S[i] == 0.

Here’s another example program. This one counts and prints the total number of times the character “a” appears in any of the program’s command-line arguments: 

int main (int argc, char * argv[]) {
    unsigned n = 0;
    for (int i = 1; i < argc; ++i)
        for (int j = 0; argv[i][j] != 0; ++j)
            if (argv[i][j] == 'a')
                ++n;
    printf("%u\n", n);
}

Longest Argument

Write a program called longest_argument that prints the longest command-line argument you pass to it. If there are more than one maximal arguments, the program must print the first one (leftmost). 

$ ./longest_argument ciao
ciao
$ ./longest_argument ciao miao bao
ciao
$ ./longest_argument gino lino pino si divertono un casino
divertono

Longest Common Prefix

Write a program called lcp that prints on the standard output the maximal length of any common prefix in two or more of its command-line arguments. For example: 

$ ./lcp ciao miao bao
0
$ ./lcp professor prefers to teach programming
3

Longest Common Prefix for All Arguments

Write a program called lcp4a that prints on the standard output the maximal length of the prefix that is common between all its command-line arguments. For example: 

$ ./lcp4a ciao miao bao
0
$ ./lcp4a professor prefers to teach programming
0
$ ./lcp4a professor prefers programming
2
